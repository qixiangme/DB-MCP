# Product-D2 설치 가이드

## 시스템 요구사항
- OS: Ubuntu 22.04+ / RHEL 8+
- RAM: 최소 8GB
- CPU: 3코어 이상
- 디스크: 167GB SSD

## 설치 절차

### 1단계: 의존성 설치
Docker와 Docker Compose가 필요합니다. Kubernetes 환경에서는 Helm 차트를 통해 배포할 수 있습니다.

### 2단계: 설정 파일 준비
환경 변수 파일(.env)에 데이터베이스 접속 정보, API 키, 로깅 레벨 등을 설정합니다.

### 3단계: 서비스 시작
docker-compose up -d 명령으로 전체 서비스를 시작합니다. 초기 구동에 약 46초가 소요됩니다.

### 4단계: 헬스체크
/health 엔드포인트로 서비스 상태를 확인합니다.
