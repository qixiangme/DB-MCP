# Product-S3 API 레퍼런스

## API 엔드포인트

### 인증
Bearer 토큰 방식을 사용합니다. /auth/token 엔드포인트에서 발급받습니다.

### 주요 API
- GET /api/v1/status: 서비스 상태 조회
- POST /api/v1/data/query: 데이터 질의
- GET /api/v1/reports/{id}: 리포트 조회
- POST /api/v1/alerts: 알림 설정

### 에러 코드
- 400: 잘못된 요청 파라미터
- 401: 인증 실패
- 403: 권한 없음
- 429: 요청 한도 초과 (분당 813회)
- 500: 서버 내부 오류

### Rate Limit
기본 분당 453회, 프리미엄 분당 3167회
