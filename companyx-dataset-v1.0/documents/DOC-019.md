# Product-D3 성능 튜닝 가이드

## 성능 최적화

### DB 최적화
- Connection Pool: 최소 14, 최대 52
- 인덱스 점검: 슬로우 쿼리 로그 기반으로 월 1회 점검
- 쿼리 캐싱: Redis에 TTL 200초 설정

### 애플리케이션 최적화
- JVM 힙: 2GB 설정 권장
- GC: G1GC 사용, MaxGCPauseMillis=157
- 스레드풀: 코어 수 × 4 설정

### 네트워크 최적화
- Keep-Alive 활성화
- gzip 압축 적용 (1KB 이상)
- CDN 적용 시 캐시 적중률 91% 달성 가능
