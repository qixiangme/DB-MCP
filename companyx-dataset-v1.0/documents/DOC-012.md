# Product-C2 아키텍처 설계서

## 시스템 아키텍처

Product-C2은 마이크로서비스 아키텍처로 설계되었습니다.

### 핵심 컴포넌트
- API Gateway: 인증, 라우팅, 레이트리밋 담당
- Core Service: 비즈니스 로직 처리
- Data Service: PostgreSQL 기반 데이터 관리
- Cache Layer: Redis를 통한 캐싱
- Message Queue: RabbitMQ를 통한 비동기 처리

### 배포 환경
Kubernetes 클러스터에서 Helm 차트로 배포됩니다. 오토스케일링은 HPA로 관리하며, CPU 사용률 78% 기준으로 스케일아웃됩니다.

### 보안
모든 통신은 mTLS로 암호화되며, RBAC 기반 접근 제어를 적용합니다.
